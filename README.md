# Portfolio

This is my personal portfolio, built to reflect how I approach frontend development — not just visually, but structurally.

I wanted this to feel like a real product, not a collection of pages. So instead of focusing only on design, I focused on clarity, maintainability, and how different parts of the application fit together.

[Live Demo](https://angelannaroby.vercel.app/)

## About

I’m a frontend developer working with React and TypeScript, currently based in Germany. Over the past few years, I’ve worked on data-driven, form-heavy applications and interfaces that are used in real production environments.

This portfolio is a small representation of that mindset.

I care about:
- building things that are clear and usable  
- writing code that is easy to understand and extend  
- keeping structure consistent across the codebase  

## Tech Stack

This project is built using:

React, TypeScript, Vite, Tailwind CSS, TanStack Router, React Hook Form, Zod, Vitest, and React Testing Library.
